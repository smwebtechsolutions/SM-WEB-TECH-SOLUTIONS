# SM WebTech Solutions Website

A responsive, GitHub Pages-ready website for **SM WebTech Solutions**.

## Included

- Responsive one-page business website
- Services: Web Design & Development, Website Redesigning, QA & Testing, Maintenance & Support, Other Web Solutions
- About section
- Four-step process section
- Contact CTA with email link
- Mobile navigation
- Supplied SM WebTech Solutions logo included in `assets/`
- No frameworks or build tools required

## Files

```text
sm-webtech-solutions/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── logo.jpg
    └── favicon.jpg
```

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `sm-webtech-solutions`.
2. Upload all files from this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide the public website URL.

## Before publishing

Replace the placeholder email address in `index.html`:

```text
hello@smwebtechsolutions.com
```

with the real business email address.

You can also update the text, service details, social links, phone number and contact information directly in `index.html`.
